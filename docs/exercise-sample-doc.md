# 【演習用】現場見学会のご案内（サンプル）

社内AI勉強会（2026-09-27）の演習1で使う練習用の文書です。自由に書き換えてください。変更履歴からいつでも元に戻せます。

## 演習の手順

1. 右上を見て、自分の権限が **編集者** になっているか確かめる
2. 「駐車場は5台分あります」に **コメント** を付けて、隣の人を ＠名前 で呼ぶ
3. **提案モード** に切り替えて、「10時〜11時」を「10:00〜11:00」に直す
4. 隣の人の提案を **承認** する（✓を押した人が「反映した人」）
5. いちばん下の「次回の見学会」に、＠ で今日の日付を入れる
