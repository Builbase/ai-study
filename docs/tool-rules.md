# Googleツール運用ルール（暫定）

**作成日:** 2026-09-20　**見直し:** 月1回の社内AI勉強会で更新

運用しながら直していく前提の暫定版です。気づいたことは、この文書にコメントで残してください。

## 1. ドキュメントの共有

**基本は「制限付き」。** 業務で必要な相手だけをメールアドレスで追加します。

| 共有の種類 | 誰が開けるか | 使う場面 |
|---|---|---|
| 制限付き | 追加した人だけ | 基本はこれ |
| 株式会社Builbase | builbase.comのアカウントを持つ社員全員 | 社内向けの資料 |
| リンクを知っている全員 | リンクを知っている人なら誰でも | **使わない**（必要なら上長に確認） |

### 権限は「何をしてもらうか」で選ぶ

| 権限 | できること | 使う場面 |
|---|---|---|
| 閲覧者 | 読むだけ | 配布資料、決定済みの文書 |
| 閲覧者（コメント可） | 読む＋コメント | 確認や意見出しを頼むとき |
| 編集者 | 本文の編集 | 一緒に書く人だけ |

### 社外に共有するときの手順

1. 相手の個人アドレスで追加する（リンク公開は使わない）
2. 権限は **閲覧者** から始める。編集が必要なときだけ編集者にする
3. 共有したら、案件のSlackチャンネルに一言残す
4. 案件が終わったら共有を外す

### 確認と修正のやり取り

- **確認したいこと** → コメント（本文は変わらない）
- **修正案** → 提案モード（元の文を消さずに残せる）
- 提案を承認して反映する担当者を、文書ごとに **1人** 決める

## 2. ドキュメントの名前と置き場所

### 名前の付け方

**形式:** 日付-種別-案件名

| 例 | 説明 |
|---|---|
| 20260927-議事録-担当者MTG | 単発の議事録 |
| 20261001-見積-○○邸 | 案件の見積 |
| 議事録-担当者MTG | 定例の議事録は1つの文書に追記するので、日付を付けない |

- 「-最新」「-final」「-修正版」を名前に付けない。版は **変更履歴** で管理する

### 置き場所

- 案件の資料 → **共有ドライブ** の案件フォルダ
- 個人のメモ → マイドライブ

## 3. スマートチップ（＠で入れる情報）

本文で「＠」を打つと、人・日付・ファイル・予定を埋め込めます。

| 入れるもの | 書く場所 | 何がうれしいか |
|---|---|---|
| ＠名前 | 議事録の「担当」 | 誰の仕事か一目で分かり、連絡先も出る |
| ＠日付 | 「期限」 | 表記がそろい、後から探しやすい |
| ＠ファイル名 | 関連資料 | URLを貼らずに済み、アクセス権の有無も見える |
| ＠予定名 | 議事録の冒頭 | 日時と参加者が自動で付く |

## 4. Geminiをドキュメントで使うとき

- 常設の事前指示はありません。**頼むたびに前提を書く**
  - 例: 「社外向けの案内文。丁寧語で200字以内。日付と場所は本文のとおり」
- 参照させたい資料は、プロンプトの中で ＠ファイル名 で指定する
- 繰り返し使う指示は、Geminiアプリの「Gem」に保存して使い回す
- **生成した文はそのまま出さない。** 社外に出す文は、書いた本人以外がもう1人読む

## 5. カレンダー

### 招待への返答

- 招待が届いたら、**翌営業日までに** 「はい」「いいえ」「未定」のいずれかを返す
- 出られないときは「新しい時間を提案」を使う
- 未返答の招待でカレンダーが見づらいときは、設定の「招待状」で「返答した招待状のみ表示」に変える

### 定例の変更は主催者だけ

| 操作 | できる人 |
|---|---|
| 周期・時刻・Meetリンクの変更 | **主催者だけ** |
| 出欠の返答、新しい時間の提案 | ゲスト |
| 主催者の引き継ぎ（「主催者を変更」） | 主催者（異動・退職の前に） |

- ゲストが変えたいときは、「新しい時間を提案」か、Slackで主催者に頼む

### 社内＋社外が入る会議

- 主催者が、社内・社外の全員をゲストに入れる
- 社内メンバーは、社内共有用のinfoアドレスを入れれば1つでまとめて招待できる
- 社内で共有したい予定は「Builbase 社内共有」カレンダーに入れる
- 社外との日程調整は、予約ページで相手に枠を選んでもらう

## 6. Meet

### 記録（録画・文字起こし・会議メモ）

- 保存先は **主催者のマイドライブ「Meet Recordings」**
- 共有ドライブへは自動振り分け（議事録の振り分けと同じ仕組み）で移す。対象と権限の範囲は別途決める
- 録画が必要な定例は、予定のMeet設定で **自動録画をオン** にする
- 録画のボタンがグレーで押せないときは、管理者が管理コンソールで録画を有効にする（Business Standardのプランでは使える）

### 同じ部屋から入るとき

- 複数の端末で入るときは **コンパニオンモード** を使う。マイクとスピーカーが最初から切れるので、ハウリングしない

### 画面共有

| 見せたいもの | 選ぶもの |
|---|---|
| 資料を1つ | タブ |
| アプリを1つ | ウィンドウ |
| 操作の実演 | 画面全体（通知も映るので注意） |

## 7. このルールの直し方

- 気づいたことは、この文書に **コメント** を付ける
- 月1回の勉強会の冒頭で、コメントを見て更新する
- 更新した人は、冒頭の作成日を書き換える
