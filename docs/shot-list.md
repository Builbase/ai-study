## 撮る順番

1. カレンダー: サンプル予定を作る（ゲスト＝自分の別アドレス1件）→ cal-01/03/04/05/13 → 保存 → cal-09/11 → 周期を変えて保存 → cal-12
2. ゲスト側（招待したアドレス）: cal-07/08/10
3. ドキュメント: サンプル文書を作る → docs-06 → docs-03 → docs-04 → docs-01/02 → docs-08
4. Meet: サンプル予定のリンクに1人で入る → meet-01/02
5. 撮り終えたらサンプル予定と文書を削除する

- 仕事用プロファイル（k-muguruma@builbase.com）で撮影。ゲストは自分の個人アドレス1件のみ。誰にも共有していない

## マスク（2026-09-18）

- `images/*.png` は `scripts-mask.py` でモザイク（10分の1に縮小→拡大）済み。対象: 全員のメールアドレス、プロフィール写真、佐々木さんの氏名チップ、実際の予定名（担当者MTG・引田・HiLMO）、Geminiの回答中の氏名
- 氏名「六車紀希」（講師本人）だけは残している
- **未加工の原本は `images/raw/` にある。**社外へ配布するときは `raw/` を外す
- 座標を直したら `python3 scripts-mask.py` を実行して再生成する（raw から作り直すので重ねがけにならない）
